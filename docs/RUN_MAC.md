# 🍎 macOS에서 실행하기

macOS에서는 **Android + iOS 스크립트를 모두 실행**할 수 있습니다. (Windows는 [Windows 가이드](./RUN_WINDOWS.md) 참고, Android만 가능)

---

## ✅ 공통 사전 준비

### 1. 스크립트를 실행할 화면까지 미리 진입해 있어야 합니다

스크립트는 버튼 클릭부터 자동으로 진행되므로, **앱 실행 → 대상 화면 진입까지는 직접 수행한 상태**에서 스크립트를 시작해야 합니다.

| 스크립트                       | 지원 플랫폼    | 실행 전 진입해야 하는 화면                                            |
| ------------------------------ | -------------- | ----------------------------------------------------------------------- |
| 익시오 - 스팸 번호 추가        | Android / iOS  | 익시오 앱 실행 → 스팸 차단 번호 추가 화면                                |
| 익시오 - 인사말 추가           | Android / iOS  | 익시오 앱 실행 → 인사말 관리 화면                                        |
| 익시오 - 스팸 단어 추가        | Android만      | 익시오 앱 실행 → 설정 → 스팸 차단/예외 설정 → 차단(또는 차단 제외) 단어 관리 |
| 모바일매니저 - 스팸 번호 추가  | Android만      | 앱 실행 → 설정 → 스팸 차단/예외 설정 → 차단(또는 차단 제외) 번호 관리   |
| 모바일매니저 - 스팸 단어 추가  | Android만      | 앱 실행 → 설정 → 스팸 차단/예외 설정 → 차단(또는 차단 제외) 단어 관리   |
| 스팸전화알림 - 스팸 번호 추가  | Android만      | 앱 실행 → 안심설정 → 번호 직접 차단(또는 차단 제외 번호 설정)            |

### 2. 다운로드 폴더는 통째로 유지

`Appium Script Runner.zip` / `Appium Script Runner Portable.zip`을 [Releases 페이지](../../../releases)에서 최신 버전을 다운로드한 뒤 압축을 풉니다.

> ⚠️ `.app` 파일만 따로 꺼내서 실행하면 동작하지 않습니다. 반드시 **폴더 전체**를 유지한 채로 실행하세요.

### 3. 최초 실행 시 "확인되지 않은 개발자" 경고

`.app`이 정식 Apple Developer 서명/공증 없이 배포되기 때문에, 브라우저로 다운로드하면 macOS가 격리(quarantine) 속성을 붙여 더블클릭으로 열리지 않을 수 있습니다. 아래 중 하나로 해결하세요.

- **우클릭(또는 Control+클릭) → 열기** 선택 후 뜨는 경고 창에서 다시 "열기" (최초 1회만 필요)
- 설정 > 개인정보 보호 및 보안 > 아래 영역에서 '그래도 열기' 선택

## 🚀 실행 방법 선택

아래 표를 보고 본인 Mac 상태에 맞는 버전을 선택하세요.

| 상태 | 사용할 버전 | 파일명 |
| ---- | ----------- | ------ |
| ADB / Node.js / Appium이 **이미 설치되어 있음** | 일반 버전 | `Appium Script Runner.zip` |
| 위 세 프로그램이 **설치되어 있지 않음** (처음 사용) | 포터블 버전 | `Appium Script Runner Portable.zip` |

### 방법 A. 일반 버전 (ADB / Node.js / Appium 기설치)

1. `Appium Script Runner.zip` 다운로드 후 압축 해제
2. `Appium Script Runner` 폴더 안의 **`Appium Script Runner.app`** 실행

### 방법 B. 포터블 버전 (아무것도 설치 안 되어 있음)

1. `Appium Script Runner Portable.zip` 다운로드 후 압축 해제
2. `Appium Script Runner Portable` 폴더 안의 **`Appium Script Runner Portable.app`** 실행
3. 최초 실행 시 Node.js / Appium / ADB를 자동으로 다운로드하여 설치합니다
   - **인터넷 연결이 필요하며, 설치에 수 분이 소요될 수 있습니다**
   - 설치가 끝나면 이후 실행부터는 바로 시작됩니다

> ℹ️ 포터블 버전의 자동 설치(Node.js / Appium / ADB)는 **Android 환경 구성만 해당**합니다. iOS 실행을 위한 Xcode/WDA 세팅은 아래 iOS 항목을 참고해 별도로 준비해야 합니다.

## 🤖 Android 실행

1. 단말을 USB로 연결하고 디버깅을 허용합니다
2. GUI 내 '디바이스 연결' 버튼으로 단말이 인식되는지 확인합니다
3. 필요하면 터미널에서 `adb devices`로도 확인 가능합니다

## 🍏 iOS 실행

iOS 스크립트 실행은 **Mac에서만 가능**하며, 포터블 버전을 사용하더라도 아래 항목은 **미리 직접 세팅되어 있어야** 합니다.

1. Xcode 설치 및 WDA(WebDriverAgent) 빌드
2. Apple Developer 계정 및 서명 설정 (개인 애플 계정으로도 7일 사용 후 재설정 가능)
3. 단말에 WDA 설치 및 신뢰 설정 완료
4. Xcode에서 **Product → Test** 실행 시 단말에 **"Automation Running"** 문구가 떠 있으면 준비 완료

> 위 4가지가 준비되지 않으면 Android용 런타임(Node.js/Appium/ADB)이 정상 설치되어 있어도 iOS 스크립트는 동작하지 않습니다.

iOS를 지원하는 스크립트는 위 표에서 "Android / iOS"로 표시된 두 개(**익시오 - 스팸 번호 추가**, **익시오 - 인사말 추가**)뿐입니다. 나머지 스크립트는 Android 전용입니다.
