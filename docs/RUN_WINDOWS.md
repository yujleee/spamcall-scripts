# 🪟 Windows에서 실행하기

Windows에서는 **Android 스크립트만 실행 가능**합니다. (iOS는 [macOS 가이드](./RUN_MAC.md) 참고)

---

## ✅ 공통 사전 준비

### 1. 스크립트를 실행할 화면까지 미리 진입해 있어야 합니다

스크립트는 버튼 클릭부터 자동으로 진행되므로, **앱 실행 → 대상 화면 진입까지는 직접 수행한 상태**에서 스크립트를 시작해야 합니다.

| 스크립트                 | 실행 전 진입해야 하는 화면                                          |
| ------------------------ | -------------------------------------------------------------------- |
| 익시오 - 스팸 번호 추가  | 익시오 앱 실행 → 스팸 차단 번호 추가 화면                            |
| 익시오 - 스팸 단어 추가  | 익시오 앱 실행 → 설정 → 스팸 차단/예외 설정 → 차단(또는 차단 제외) 단어 관리 |
| 익시오 - 인사말 추가     | 익시오 앱 실행 → 인사말 관리 화면                                     |
| 모바일매니저 - 스팸 번호 추가 | 앱 실행 → 설정 → 스팸 차단/예외 설정 → 차단(또는 차단 제외) 번호 관리 |
| 모바일매니저 - 스팸 단어 추가 | 앱 실행 → 설정 → 스팸 차단/예외 설정 → 차단(또는 차단 제외) 단어 관리 |
| 스팸전화알림 - 스팸 번호 추가 | 앱 실행 → 안심설정 → 번호 직접 차단(또는 차단 제외 번호 설정)        |

### 2. 단말 USB 연결 및 디버깅 허용

단말을 USB로 연결하고 개발자 옵션에서 **USB 디버깅을 허용**해야 합니다.

### 3. 다운로드 폴더는 통째로 유지

`Appium Script Runner.zip` / `Appium Script Runner Portable.zip`을 [Releases 페이지](../../../releases)에서 최신 버전을 다운로드한 뒤 압축을 풉니다.

> ⚠️ `.exe` 파일만 따로 꺼내서 실행하면 동작하지 않습니다. 반드시 **폴더 전체**를 유지한 채로 실행하세요.

---

## 🚀 실행 방법 선택

아래 표를 보고 본인 PC 상태에 맞는 버전을 선택하세요.

| 상태 | 사용할 버전 | 파일명 |
| ---- | ----------- | ------ |
| ADB / Node.js / Appium이 **이미 설치되어 있음** | 일반 버전 | `Appium Script Runner.zip` |
| 위 세 프로그램이 **설치되어 있지 않음** (처음 사용) | 포터블 버전 | `Appium Script Runner Portable.zip` |

### 방법 A. 일반 버전 (ADB / Node.js / Appium 기설치)

1. `Appium Script Runner.zip` 다운로드 후 압축 해제
2. `Appium Script Runner` 폴더 안의 **`Appium Script Runner.exe`** 실행

### 방법 B. 포터블 버전 (아무것도 설치 안 되어 있음)

1. `Appium Script Runner Portable.zip` 다운로드 후 압축 해제
2. `Appium Script Runner Portable` 폴더 안의 **`Appium Script Runner Portable.exe`** 실행
3. 최초 실행 시 Node.js / Appium / ADB를 자동으로 다운로드하여 설치합니다
   - **인터넷 연결이 필요하며, 설치에 수 분이 소요될 수 있습니다**
   - 설치가 끝나면 이후 실행부터는 바로 시작됩니다

## 🔧 Android 디바이스 연결이 안 될 때

GUI 내 '디바이스 연결' 버튼을 눌러도 인식되지 않는다면:

1. cmd 창을 열어 `adb devices` 입력 → 단말 정보가 나오면 정상 연결된 상태입니다.
2. 단말 정보가 안 나온다면, 단말 케이블을 다시 연결하고 디버깅 허용 팝업을 다시 확인하세요.

### Privacy-i 프로그램이 설치되어 있는 경우

**Privacy-i가 설치되어 있으면 adb 연결이 원활하지 않을 수 있습니다.** 아래 순서로 driver를 재활성화하세요.

1. 단말을 USB로 연결하고 디버깅을 허용합니다
2. 제어판 → **장치 관리자** 실행
3. **Android Device** 항목 아래 **SAMSUNG Android ADB Interface**(제조사에 따라 명칭 다를 수 있음)를 우클릭
4. **디바이스 사용 안 함 → 다시 사용**을 두어 번 반복 실행
5. cmd에서 `adb devices` 입력 시 단말 정보가 나오면 정상 연결
